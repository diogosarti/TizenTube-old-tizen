# TizenTube — Old Tizen

[English README](README.md)

Это форк [reisxd/TizenTube](https://github.com/reisxd/TizenTube), основанный на **TizenTube Standalone v2.1.1** и переделанный для старых телевизоров Samsung. Главное отличие — **воспроизведение YouTube с работающим SponsorBlock на Tizen 2.4.0**. **Поддержка TLS 1.3 включена для запросов API и видео**; по умолчанию версия TLS 1.2–1.3 выбирается автоматически. Также сохранены последующие изменения модулей исходного проекта.

Приложение работает автономно на телевизоре: напрямую загружает интерфейс YouTube TV и подключает модификации TizenTube через загрузчик, адаптированный для старого WebKit. Во время просмотра компьютер, внешний прокси и локальный сервис не нужны.

**Проверенное устройство:** Samsung UE50KU6000 (серия KU6000), Tizen 2.4.0, прошивка T-JZL6DEUC-1260.1. Работа на других моделях не подтверждена.

## Установка

В ZIP из релиза находится неподписанный WGT. Перед установкой его нужно подписать профилем сертификата Samsung, который включает DUID вашего телевизора. Личные сертификаты и подписи для конкретного устройства в архив не входят.

1. Скачайте `TizenTube-old-tizen-v2.3.9.zip` из [последнего релиза](https://github.com/numbereleven-a/TizenTube-old-tizen/releases/latest) и извлеките `TizenTube-old-tizen-v2.3.9-resign-required.wgt`.
2. Установите Tizen Studio, Samsung TV Extension и Certificate Manager.
3. Включите Developer Mode, подключите ТВ и создайте для него профиль сертификата Samsung. См. [инструкцию по сертификатам](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/creating-certificates.html) и [подключению телевизора](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html).
4. [Импортируйте WGT как проект Tizen](https://developer.samsung.com/smarttv/develop/getting-started/creating-tv-applications/importing-tv-applications.html), выберите свой профиль сертификата и соберите подписанный пакет.
5. Установите полученный WGT на подключённый ТВ и запустите **TizenTube-old-tizen** из меню приложений.

YouTube запускается с включёнными модификациями. Приложение не распространяется через Samsung Apps. Инструкция по сборке из исходников приведена ниже.

### Обновление установленного приложения

Релиз сохраняет идентификаторы приложения из финальных локальных тестовых сборок. Подписывайте обновления тем же сертификатом автора и устанавливайте поверх существующего приложения: это сохраняет аккаунт и настройки. При истёкшей или отозванной авторизации вход может потребоваться повторно. Удаление приложения очищает его локальные данные.

## SponsorBlock и воспроизведение

- **SponsorBlock:** пропускает известные спонсорские вставки и показывает их отметки на шкале, в том числе при перемотке. [SponsorBlock](https://sponsor.ajay.app/) использует временные отметки, добавленные сообществом, для рекламы, встроенной авторами в сам ролик. Если вставка ещё не размечена, автоматического пропуска не будет.
- **Аккаунт YouTube:** сохранён штатный вход через QR-код. На проверенном ТВ подтверждены вход, сохранение сессии и синхронизация истории просмотров.
- **Плеер:** на указанной конфигурации проверены видео, звук, пауза, перемотка, отметки SponsorBlock и повторный запуск приложения.

Блокировка рекламы и другие функции TizenTube сохранены в исходниках. Полная совместимость всех функций исходного проекта не заявляется.

## Управление и диагностика

| Кнопка | Действие |
|---|---|
| Стрелки / Enter / Return | Обычная навигация YouTube |
| Зелёная | Настройки TizenTube |
| Красная или 1 | Показать или скрыть журнал в памяти |
| 2 | Перезагрузить YouTube в текущем режиме |
| Синяя или 4 | Открыть диагностику и остановить видео |

В диагностике доступны **Restart TizenTube** и **Try without modifications**. Второй пункт отключает модификации для сравнения в текущем сеансе; следующий запуск снова включает TizenTube. Return в диагностике закрывает приложение.

Журнал скрыт по умолчанию, хранится только в памяти и очищается при закрытии приложения. В нём остаются ошибки, результаты запросов истории, состояние плеера и сведения о буфере. Токены, cookies и полные адреса запросов намеренно не записываются; чувствительные значения диагностических строк скрываются. Web Inspector включается отдельным запуском для отладки; обычный запуск из меню ТВ его не включает. См. [руководство по сборке и отладке](legacy/README.md).

## Требования и совместимость

Подтверждена только указанная конфигурация KU6000/Tizen 2.4.0. Нужны среда веб-приложений Samsung Tizen, работающее воспроизведение/MSE, поддерживаемые видео- и аудиодекодеры, доступ к YouTube, его видеосерверам и SponsorBlock.

Минимум Tizen 2.4 в манифесте — требование к установке, а не подтверждение совместимости со всеми телевизорами Tizen 2.4 и новее. Другие модели, прошивки, кодеки и все разрешения видео не проверялись. YouTube может менять интерфейс и скрипты независимо от этого проекта.

На проверенной конфигурации вход через QR в мобильном приложении YouTube иногда требовал второй попытки. Эта проблема на стороне телефона не устранена. При ошибке подключения открывается диагностика, откуда можно вручную повторить загрузку.

HTTPS-запросы API и видео через MSE поддерживают TLS 1.3 благодаря встроенному ARM-модулю NaCl. Зелёная → Сеть / TLS позволяет выбрать Авто (TLS 1.2–1.3), принудительно TLS 1.2 или TLS 1.3 и показывает согласованную версию отдельно для API и видео. Авто выбирает версию для каждого соединения; принудительный TLS 1.3 не позволяет подключиться к серверам только с TLS 1.2. Ресурсы DOM используют системный стек ТВ, версия TLS которого неизвестна. См. [руководство по TLS и результаты проверки](legacy/README.md).

## Исходный проект

Основа — [TizenTube Standalone v2.1.1](https://github.com/reisxd/TizenTube/releases/tag/v2.1.1). Для проверенного Tizen 2.4.0 форк заменяет загрузчик с сервисом, поставляет ES5-совместимые скрипты и адаптирует воспроизведение и перемотку SponsorBlock. Уведомления об авторских правах и лицензии исходного проекта сохранены.

## Сборка

Установите Node.js и Tizen Studio с Samsung TV Extension и инструментами сертификатов. Из корня репозитория:

```text
npm --prefix mods install
npm --prefix legacy install
npm --prefix legacy test
npm --prefix legacy run build
```

Сборка проверяет JavaScript пакета на совместимость с ES5 и создаёт `artifacts/2.3.9/TizenTube-old-tizen-v2.3.9.zip`. Подпишите подготовленный виджет своим профилем сертификата:

```text
tizen package -t wgt -s YOUR_CERTIFICATE_PROFILE -o artifacts/2.3.9/signed -- legacy/dist/widget-2.3.9
```

Релиз собирается из загрузчика `legacy/widget`. Старые каталоги `standalone` и исходники сервисов сохранены из upstream и в этот WGT не включены.
